# M0.1 Report

Implemented explicit `Confidence` metadata and graph endpoint/ID validation. Query indexing now supports exact and partial lookup plus bounded shortest-path traversal.

Known gaps: IDs remain canonical sequential IDs rather than persisted content-derived IDs; import and call resolution remains conservative heuristic; unresolved and ambiguous relations are not yet explicit records.

Validation: `cargo fmt`, `cargo check --all-targets --all-features`, `cargo test --lib`, and strict Clippy pass.
