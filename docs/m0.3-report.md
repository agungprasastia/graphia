# M0.3 Report

Implemented explicit versioned binary storage at `.graphia/index.bin`.

- 96-byte little-endian header with magic, version, endian marker, header size, section offsets and lengths, record counts, and SHA-256 checksum.
- Independent node and edge sections with explicit fixed-width scalar fields and length-prefixed UTF-8 strings.
- Loader validates magic, version, endian marker, header size, offsets, lengths, counts, checksum, section exhaustion, UTF-8, enum codes, and graph invariants.
- Atomic temporary-file write, file `sync_all`, and replacement preserved. This provides atomic visibility and flushes file contents before replacement; parent-directory syncing is not claimed, so crash durability of the directory entry is not guaranteed.
- JSON remains available for human-readable export; binary stores logical graph values only.
- Added round-trip, corruption, trailing-byte, offset, and CLI binary-to-JSON export coverage.

Format reference: [`docs/index-format.md`](index-format.md).
