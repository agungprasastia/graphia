# M2.2 Model Context Protocol (MCP) Server Milestone Report

## Overview
Graphia M2.2 introduces a zero-overhead, read-only JSON-RPC 2.0 stdio Model Context Protocol (MCP) server. The server exposes structural graph queries, repository intelligence, and token-budgeted AI context generation tools to LLMs and AI coding assistants with strict stdio isolation and path traversal sandboxing.

## Implemented Architecture

### 1. Protocol Schemas (`src/mcp/protocol.rs`)
- Full compliance with JSON-RPC 2.0:
  - `JsonRpcRequest`, `JsonRpcResponse`, `JsonRpcNotification`, `JsonRpcErrorObject`, `RequestId`.
- MCP Core schemas (`protocol_version: "2024-11-05"`):
  - `InitializeParams`, `InitializeResult`, `ServerCapabilities`, `ToolsCapability`, `Implementation`.
  - `Tool`, `ListToolsResult`, `CallToolParams`, `CallToolResult`, `Content::Text`.

### 2. Transport & Stdio Isolation (`src/mcp/transport.rs`)
- `StdioReader`: Line-delimited buffered JSON-RPC parser with EOF and whitespace handling.
- `StdioWriter`: Formats and writes single-line JSON responses followed by newline and immediate flush.
- Protocol isolation: Only valid single-line JSON-RPC messages are emitted on `stdout`. Server logging and diagnostics are written strictly to `stderr`.

### 3. Tool Suite (`src/mcp/tools.rs`)
Exposes 11 read-only tools with typed `inputSchema` definitions:
1. `graphia_search_symbol`: Structural search with query, kind filter, file filter, and limit.
2. `graphia_get_symbol`: Detailed symbol definition, location, container, callers, callees, and imports.
3. `graphia_find_callers`: Inbound callers traversal up to specified depth.
4. `graphia_find_callees`: Outbound function/method calls up to specified depth.
5. `graphia_find_references`: Categorized references across calls, types, and imports.
6. `graphia_dependency_path`: Shortest structural path between two symbols with cycle protection.
7. `graphia_neighborhood`: Structural neighborhood around a symbol (container, children, callers, callees, imports, implementations, tests).
8. `graphia_impact`: Blast radius and change surface impact analysis.
9. `graphia_find_tests`: Deterministic test discovery mapped to symbols or source files.
10. `graphia_architecture`: Structural overview of repository (totals, entrypoints, cycles, communities, high-centrality modules).
11. `graphia_context`: Token-budgeted minimal sufficient AI context bundle generation.

### 4. Error Handling & Sandboxing (`src/mcp/error.rs`, `src/mcp/server.rs`)
- Structured error codes:
  - Standard JSON-RPC: `-32700` (Parse), `-32600` (Invalid Request), `-32601` (Method Not Found), `-32602` (Invalid Params), `-32603` (Internal Error).
  - Custom MCP: `-32000` (Repo Not Found), `-32001` (Graph Not Built), `-32002` (Path Traversal Detected), `-32003` (Tool Execution Error), `-32004` (Uninitialized).
- Sandbox isolation: All path parameters (`file`, `path`, etc.) are validated to prevent directory traversal (`..`, parent navigation, absolute paths outside repo boundary).

### 5. CLI Integration (`src/cli/mod.rs`)
- Subcommand:
  ```bash
  graphia mcp [REPO]
  ```
  Launches the stdio MCP server loop bound to the specified repository (default: current working directory).

  - `test_mcp_initialize_and_notification`: Validates protocol initialization handshake.
  - `test_mcp_tools_list`: Tests tool enumeration.
  - `test_mcp_all_11_tools_execution`: End-to-end execution of all 11 tools with mocked graph and filesystem.
  - `test_stdio_isolation_and_stream_roundtrip`: Verifies clean line-delimited stdio roundtrip.
  - `test_path_traversal_sandboxing`: Confirms rejection of directory traversal attempts.

  - `test_cli_mcp_invocation`: Tests CLI subcommand construction.
