## Key Milestone 4.1.1 Upgrades & Evidence

### 1. Fully Populated Parser IR & Canonical Signatures
- **Previous State**: Parsers returned `Vec::new()` for `definitions`, `references`, `exports`, and `type_references`. `signature` was almost always `None`.
- **New State**:
  - `src/parser/mod.rs`: Rust & Python parsers populate `definitions`, `exports`, `type_references`, `references`, and extract canonical whitespace-normalized signatures (e.g. `login(user:User,password:&str)->bool`).
  - `src/parse/*.rs`: JavaScript/TypeScript, Go, C/C++, Java, C#, Kotlin, Zig, PHP, Ruby, and Swift parsers extract functions, methods, constructors, namespaces, packages, and interfaces with visibility and normalized signatures into semantic IR.
- **Verification**: `tests/parser_ir.rs` (4/4 tests pass).

### 2. Normalized IR-Driven Graph Builder & Multi-Kind Resolution
- **Previous State**: `build_graph()` only consumed legacy `symbols`, `imports`, and `calls`.
- **New State**: `build_graph()` in `src/graph/mod.rs` creates `Node` elements from `ParsedFile.definitions` and automatically emits `Exports`, `TypeReferences`, `References`, `Imports`, `Calls`, and `Contains` edges.
- **Verification**: `tests/graph_resolution.rs` (1/1 tests pass).

### 3. True Incremental Workspace Engine
- **Previous State**: `update_repository()` performed a complete scan and full graph rebuild on every change.
- **New State**: `IncrementalWorkspace` in `src/incremental.rs` caches file ASTs and applies `SemanticAction::Created`, `Modified`, `Removed`, `Renamed` directly to in-memory AST state, updating only dirty files and ensuring canonical equality (`incremental_graph == clean_rebuild_graph`).
- **Verification**: `tests/incremental_workspace.rs` (1/1 tests pass).

### 4. Hardened Live Daemon Lifecycle & Health State
- **Previous State**: Queued semantic actions were drained and discarded, triggering indiscriminate full reconciles.
- **New State**: `LiveStateManager` in `src/daemon/state.rs` and `DaemonServer` in `src/daemon/server.rs` apply semantic actions incrementally via `workspace.apply_changes()`, track health (`Healthy`, `Updating`, `Dirty`, `Recovering`, `Failed`), and isolate atomic snapshot generations.
- **Verification**: `tests/daemon_lifecycle.rs` (1/1 tests pass).

### 5. Stale Index Detection & Auto-Index MCP Server
- **Previous State**: MCP had basic error logging without auto-index building options.
- **New State**: `McpServer::new_with_auto_index()` in `src/mcp/server.rs` rejects unindexed repositories by default with clear error messages, and automatically builds/indexes when `--auto-index` is supplied.
- **Verification**: `tests/mcp_lifecycle.rs` (2/2 tests pass).

### 6. AST Typeflow, Semantic Diffing & Path-Aware Boundary Checks
- **Previous State**: Dataflow relied on generic BFS reachability; typeflow was based on naive string splitting.
- **New State**: `extract_intraprocedural_typeflow` derives parameter seeds, assignment edges, and return sources directly. Semantic diffing accurately matches nodes by `SemanticNodeKey`. `check_architecture_boundaries` validates layer paths and allowed dependencies without false positives.
- **Verification**: `tests/advanced_semantics.rs` (3/3 tests pass).
