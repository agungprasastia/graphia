# M1.2 Graph Analysis Algorithms Report

## Overview
Milestone M1.2 introduces native, strictly deterministic, resource-bounded graph analysis algorithms directly over Graphia's in-memory graph representation without external dependencies (no SQLite, no Python, no NetworkX).

## Architecture

The graph analysis engine is encapsulated within `src/analysis/`:
- `src/analysis/projection.rs`: Multi-level projection (Symbol, File, Module) with weighted edge aggregation and edge-kind filtering.
- `src/analysis/scc.rs`: Non-recursive Tarjan's Strongly Connected Components algorithm with deterministic component sorting and canonical ID assignment.
- `src/analysis/cycles.rs`: Deterministic elementary cycle detection using SCC pruning, canonical cycle rotation representation, and configurable cycle limits.
- `src/analysis/centrality.rs`: In-degree, out-degree, degree centrality, and bounded PageRank with power iteration and dangling-node distribution.
- `src/analysis/coupling.rs`: Afferent coupling ($C_a$ / Fan-in), Efferent coupling ($C_e$ / Fan-out), and Instability metric ($I = \frac{C_e}{C_a + C_e}$) with zero-division protection.
- `src/analysis/hotspots.rs`: Structural hotspot scoring combining fan-in/fan-out stress, PageRank centrality, and cycle participation penalties.
- `src/analysis/communities.rs`: Deterministic Label Propagation Community Detection with fixed initialization and canonical tie-breaking.
- `src/analysis/mod.rs`: High-level orchestrator producing versioned `AnalysisReport` (`"analysis_version": 1`).

## Algorithm Specifications

### 1. Multi-Level Graph Projection (`projection.rs`)
- **Symbol Level**: Retains individual code symbols (functions, methods, classes, structs, traits, interfaces) and maps inter-symbol edges.
- **File Level**: Collapses symbols to their enclosing file paths, summing cross-file references into weighted aggregated edges.
- **Module Level**: Groups files by their parent directory path, aggregating inter-module dependencies.

### 2. Tarjan's Strongly Connected Components (`scc.rs`)
- Implemented with an explicit iteration stack to prevent call-stack overflow on deep graphs.
- Components are classified as trivial (size = 1 without self-loop) or non-trivial.
- Deterministic output sorted by size descending, then lexicographical first member name.

### 3. Cycle Extraction (`cycles.rs`)
- Bounded depth-first search restricted within non-trivial SCCs.
- Canonical cycle normalization: cycles are represented starting from the node with the minimum index to avoid cyclic permutations.
- Configurable limits: `max_length`, `max_cycles`, and optional `include_self_loops`.

### 4. Degree Centrality & PageRank (`centrality.rs`)
- PageRank computes stationary probability distribution using power iteration:
  $$PR(u) = \frac{1 - d}{N} + d \sum_{v \in In(u)} \frac{PR(v)}{Out(v)} + d \frac{\sum_{w \in Dangling} PR(w)}{N}$$
- Convergence threshold $\epsilon = 10^{-6}$ with bounded maximum iterations ($100$).

### 5. Coupling & Instability (`coupling.rs`)
- Afferent Coupling ($C_a$): Number of incoming dependencies.
- Efferent Coupling ($C_e$): Number of outgoing dependencies.
- Instability ($I$): $I = \frac{C_e}{C_a + C_e}$, defined as $0.0$ when $C_a + C_e = 0$.

### 6. Structural Hotspots (`hotspots.rs`)
- Combines structural fan-in / fan-out pressure, PageRank, and SCC cycle participation:
  $$\text{Score} = (2 \cdot \text{FanIn} + \text{FanOut}) \cdot (1 + 10 \cdot PR) \cdot (\text{SCC Penalty})$$

### 7. Community Detection (`communities.rs`)
- Deterministic Label Propagation Algorithm (LPA).
- Ties broken canonically by selecting the lowest numerical/lexicographical label ID.

## CLI Commands

CLI subcommands added in `src/cli/mod.rs`:
- `graphia analyze <repo> [--level <symbol|file|module>] [--edge <kind>] [--limit <n>] [--format <human|json>]`
- `graphia cycles <repo> [--level <symbol|file|module>] [--edge <kind>] [--limit <n>] [--format <human|json>]`
- `graphia hotspots <repo> [--level <symbol|file|module>] [--limit <n>] [--format <human|json>]`
- `graphia communities <repo> [--level <symbol|file|module>] [--limit <n>] [--format <human|json>]`

All JSON outputs adhere to versioned schema contracts (`analysis_version: 1`).
