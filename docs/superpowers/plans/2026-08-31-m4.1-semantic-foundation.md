# Graphia M4.1 Semantic Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace location-based identities and narrow parser facts with a deterministic, overload-safe semantic model, compact normalized IR, truthful language coverage, and explicitly versioned storage.

**Architecture:** Source analyzers emit unresolved compact facts into `ParsedFile`; graph construction creates nodes from `SemanticNodeKey`; one `ResolutionEngine` links supported relation kinds while preserving unresolved and ambiguous results. Native index and parsed-cache versions form a hard compatibility boundary around changed identity and model semantics.

**Tech Stack:** Rust 1.85+, edition 2024, Tree-sitter 0.24 language grammars, serde, sha2, existing Graphia binary storage, built-in Rust test harness.

**Spec:** `docs/superpowers/specs/2026-08-31-m4.1-semantic-foundation-design.md`

## Global Constraints

- Preserve existing correct behavior; no rewrite and no M5 work.
- Priority: correctness, semantic accuracy, determinism, consistency, memory efficiency, performance, feature breadth.
- Keep Tree-sitter trees temporary; persist compact normalized facts only.
- Preserve unresolved and ambiguous outcomes; never choose first candidate by iteration order.
- No new runtime dependency unless an existing mechanism cannot satisfy correctness.
- Remove `missing_docs = "allow"`; add no broad `allow`, `RUSTFLAGS`, or equivalent suppression.
- Use targeted tests during tasks; run full all-target/all-feature validation once at workstream boundary.
- Do not modify unrelated concurrent work, including existing unstaged `README.md` changes.

## File and responsibility map

- `src/model/mod.rs`: semantic keys, physical locations, normalized kinds, metadata, confidence, serialization codes.
- `src/parser/mod.rs`: compact unresolved IR records and parser dispatch.
- `src/parse/analyzer.rs`: shared extraction helpers and canonical signature/visibility utilities.
- `src/parse/*.rs`: language-family semantic extraction.
- `src/scan/mod.rs`: deterministic repository-aware C/C++ header classification.
- `src/graph/mod.rs`: semantic node construction, relation materialization, canonicalization, resolution report.
- `src/resolve/{mod,scope,import,candidate}.rs`: scopes, indexes, candidate generation, ambiguity-preserving relation resolution.
- `src/storage/mod.rs`: native index version and metadata serialization.
- `src/incremental.rs`: parsed-cache version and invalidation only; affected graph updates belong to workstream 2.
- `tests/semantic_identity.rs`: stable and overload-safe identity regressions.
- `tests/semantic_model.rs`: normalized extraction and metadata fixtures.
- `tests/resolution_engine.rs`: cross-file relation and ambiguity regressions.
- `tests/systems_languages.rs`, `tests/javascript_languages.rs`, `tests/managed_languages.rs`, `tests/modern_languages.rs`: language-family coverage.
- `docs/m4.1-closure-audit.md`: source-backed claim/gap ledger.
- `docs/language-support.md`: capability matrix with evidence and limitations.
