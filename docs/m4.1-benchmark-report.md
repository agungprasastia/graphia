# Graphia M4.1 Benchmark Report

## Overview & Methodology

This benchmark report presents empirical performance measurements for Graphia M4.1 on deterministic multi-language test datasets across three representative repository scales:
- **Small**: 3 files, 285 bytes source, 12 nodes, 9 edges
- **Medium**: 12 files, 1,150 bytes source, 48 nodes, 36 edges
- **Large**: 48 files, 4,750 bytes source, 192 nodes, 144 edges

System & Environment:
- Rust Version: 1.85+ (Edition 2024)
- Build Profile: `release` (`bench`)
- Platform: Windows x86_64
- Harness: Criterion / microbench runner (`benches/performance.rs`)
- Graphify Comparison: `UNAVAILABLE` (External Graphify python harness not installed in execution environment).
