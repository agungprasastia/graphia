# M2.1 AI Context Engine Milestone Report

## Overview
Graphia M2.1 implements a deterministic, graph-guided, token-budgeted AI Context Engine. It extracts minimal sufficient source slices for symbols, files, search queries, or git-changed files without dumping irrelevant lines or cutting through arbitrary token boundaries.

## Implemented Architecture

### 1. Seed Resolution (`src/context/request.rs`)
- Resolves context seeds from:
  - `--symbol <name>`: Exact and fuzzy symbol lookup using `QueryIndex`.
  - `--file <path>`: Prefix and path matching across graph nodes.
  - `--query "<text>"`: Structural & lexical ranked search scoring.
  - `--changed`: Incremental repository change analysis comparing cached metadata.

### 2. Candidate Expansion (`src/context/candidate.rs`)
- Bounded BFS expansion from seeds traversing:
  - Enclosing containers / modules / classes (`Contains`)
  - Outgoing function/method calls (`Callees`)
  - Incoming function/method calls (`Callers`)
  - Trait / Interface implementations (`Implements`, `Inherits`)
  - Referenced types (`Struct`, `Trait`, `Interface`, `Class`)
  - Associated test cases via test discovery mapping.
- Depth guards (default: 3, max: 5) and candidate ceiling controls.

### 3. Relevance Scoring & Distance Decay (`src/context/ranking.rs`)
- Deterministic decay scoring model:
  - Seed symbols: `1000.0`
  - Direct Callers / Callees: `800.0`
  - Enclosing Container / Struct: `750.0`
  - Referenced Types: `700.0`
  - Trait / Interface Implementations: `650.0`
  - Distance 2 Neighbors: `500.0`
  - Distance 3 Neighbors: `250.0`
  - Associated Tests: `200.0`
- Deterministic tie-breaking by score, distance, alphabetical qualified name, and node ID.

### 4. Budget Allocation & Enforcement (`src/context/budget.rs`)
- Supports budget limits configured by:
  - `ApproxTokens` (~4 chars / token heuristic using `div_ceil(4)`)
  - `Bytes`
  - `Characters`
- Priority-ordered inclusion guaranteeing syntax-complete code slices without splitting lines.

### 5. AST Source Slicing & Deduplication (`src/context/slice.rs`, `src/context/bundle.rs`)
- Precise line-range extraction from source files.
- Overlap & nested slice deduplication (e.g. enclosing struct vs inner method).
- Versioned context schema output (`schema_version: 1`).

### 6. CLI Subcommand (`src/cli/mod.rs`)
- Command:
  ```bash
  graphia context [--symbol <sym>] [--file <path>] [--query <text>] [--changed] [--token-budget <n>] [--budget-type tokens|bytes|chars] [--depth <n>] [--limit <n>] [--format human|json]
  ```
